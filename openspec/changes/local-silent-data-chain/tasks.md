# Tasks

## Delivery: pull requests

The work lands in these PRs, in this order, as one stack managed with `gh stack`. Group N of this file is PR N. Each PR carries the tests and docs of its own tasks, and passes `pnpm lint` and the tests and typecheck of each package it touches. Branches follow AGENTS.md (`feat/`, `fix/`, `chore/`, `docs/`). No commit, push or PR is made without the user's explicit instruction each time.

| PR | Title | Branch | Tasks | Base | Changeset |
|---|---|---|---|---|---|
| 1 | `openspec(e2e, deploy): local Silent Data chain (H6)` | `docs/openspec-local-silent-data-chain` | this change folder only | `main` (bottom of the stack) | none |
| 2 | `feat(e2e): the BYO wallet fixture takes a CHAINS list (H6)` | `feat/wallet-byo-chains-list` | group 2 | PR 1 | none (private package) |
| 3 | `feat(e2e): Silent Data gateway and the Devnet SD state (H6)` | `feat/silent-data-gateway` | group 3 | PR 2 | `giano-contracts` patch, `giano-wallet-kit` patch |
